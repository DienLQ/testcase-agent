# Update an existing generated artifact

Send an explicit request in **UP Testcase**:

```text
Update output/<feature-id>/test-cases-v001.md.
Read the configured PRD, selective SRS evidence, supporting inputs, and template first.
Change: <describe the requested change>.
Preserve unaffected IDs and content. Do not duplicate an equivalent case.
If adding a case, use the next unused ID above the current maximum.
Update the analysis, review, and change log, then read every saved artifact back.
Do not modify any input document.
```
